How it works

  1. Generate & download the zia_xxx.conf
  2. Import into WireGuard → turn VPN ON
  3. Open the login link (only reachable while on that VPN)
  4. Open MLBB first (site detects device)
  5. Paste target and_ device ID + choose server
  6. Check → see Player ID / Server / IGN
  7. Apply Changes → success (or try another ID if banned)
  8. Turn VPN off → clear MLBB → reopen → switched

Configs expire after 3 hours. Successful switch = one-time use (site goes down). Banned IDs = unlimited retry.
